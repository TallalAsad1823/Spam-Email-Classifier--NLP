Text Preprocessing
i
Text Preprocessing
Raw message is cleaned before analysis. Converted to lowercase, punctuation removed, only alphabetic words kept. "FREE!" and "free" become the same word.

Example: "WIN £1000 NOW!!!" → "win 1000 now"
NLP Step 1
2
Tokenization
i
Tokenization
The message is split into individual words called tokens using NLTK's word_tokenize().

"Win free prize now" → ["Win", "free", "prize", "now"]

Each token is processed separately by the model.
nltk.word_tokenize()
3
Stop Words Removal
i
Stop Words Removal
Common words like "the", "is", "a", "an", "and" are removed — they appear in every message and add no value for spam detection.

NLTK has 179 built-in English stop words.

"this is a free offer" → "free offer"
nltk.corpus.stopwords
4
Lemmatization
i
Lemmatization
Words are reduced to their root (lemma) form so different versions of a word are treated as one.

• "running" → "run"
• "prizes" → "prize"
• "winning" → "win"

Reduces vocabulary size and improves accuracy.
WordNetLemmatizer
5
Bag of Words (BOW)
i
Bag of Words
Message is converted into a number vector. Each position = one word from the top 3000 vocabulary. Value = how many times that word appears.

["free", "win", "prize"] → [1, 1, 1, 0, 0, ...]

Model reads numbers, not text.
CountVectorizer
6
Naive Bayes Classification
i
Naive Bayes Classifier
Calculates probability of spam vs not-spam based on which words appear. Learned from 5,572 labeled messages.

Logic: "if FREE + WIN appear together → high spam probability"

Output: SPAM or NOT SPAM + confidence %
